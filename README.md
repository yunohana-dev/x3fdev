# x3fdev

Sigma の X3F（Foveon RAW）を、ユーザーの好みに合わせて自動で現像し、JPEG に書き出すツール。

- 好みは、候補画像のペア比較を繰り返して学習する（チューニング）
- 機種ごとの色は、Sigma Photo Pro（SPP）の出力を基準に補正する（キャリブレーション）
- 写真ごとの現像パラメータはサイドカーファイルに保存し、後から同じ結果を再現できる

対象機種（初期）: dp0 Quattro、DP2（無印）、SD1 Merrill

## 前提

- WSL2（Linux）上で実行する
- **プロジェクトルート（またはその配下）でコマンドを実行する**
- ツールの状態（プロファイル、評価ログ、キャッシュ）はすべてプロジェクトルートの中に置く。外にあるのは入力の X3F、そのサイドカーファイル、出力の JPEG だけ

## 使い方

```sh
uv run x3fdev <サブコマンド> [オプション]
```

| サブコマンド | 内容 |
|---|---|
| `info` | X3F の情報表示（機種判定、デコード可否） |
| `decode` | X3F → linear TIFF（検証・デバッグ用） |
| `calibrate` | カメラプロファイルの作成 |
| `tune init` / `run` / `fit` / `status` | スタイルのチューニング |
| `develop` | 現像と書き出し |
| `geotag` | JPEG へのジオタグ付与 |
| `cache du` / `clear` | キャッシュの管理 |

例:

```sh
uv run x3fdev calibrate --refs ~/calib/dp0q
uv run x3fdev tune run --input /mnt/d/photos/2025 --sample 20
uv run x3fdev develop /mnt/d/photos/2025/*.X3F --output ~/out --save-sidecar
uv run x3fdev develop /mnt/d/photos/2025/*.X3F --output ~/out --from-sidecar
uv run x3fdev geotag ~/out/*.jpg --gpx ~/logs/*.gpx --tz +09:00
```

各オプションの詳細は [docs/design.md](docs/design.md) の「CLI」を参照。

## 用語

| 用語 | 定義 |
|---|---|
| RAW | センサーの出力をほぼ未加工で記録した画像データ |
| X3F | Sigma の Foveon センサー機が出力する RAW 形式 |
| 現像 | RAW から表示・配布用の画像（本ツールでは JPEG）を生成する処理全体 |
| デコード | X3F を読み、linear RGB（明るさに比例した値）の画像に変換する処理。現像の最初の段階 |
| パイプライン | デコード後の画像に、現像パラメータを順に適用して出力画像を得る処理の並び |
| 現像パラメータ | 現像の結果を決める値の集合（露出補正、ホワイトバランス、トーンカーブ、彩度など） |
| カメラプロファイル | 機種ごとの色補正の定義。正確な色を得るためのもので、好みは含まない |
| スタイル | 好みの色調を表す、機種に依存しない現像パラメータの集合 |
| プロファイル | カメラプロファイルとスタイルの総称 |
| キャリブレーション | 基準画像（SPP の標準設定での出力）に合わせて、カメラプロファイルを作る工程 |
| チューニング | 候補画像の比較評価を繰り返し、スタイルを決める工程（手法は嗜好学習） |
| ペア比較 | 2 枚の候補画像からより好ましい方を選ぶ評価方式 |
| セッション | 1 回のチューニングで行う、一連のペア比較 |
| 評価ログ | ペア比較の結果の記録。スタイルを再学習するための元データ |
| 参照画像 | 好みの方向を示すためにユーザーが与える画像（他機種・他人の写真でもよい） |
| 参照画像による初期化 | 参照画像の色調の統計からスタイルの初期値を作ること |
| 画像ごとのパラメータ | 撮影ごとに異なる値（露出補正、ホワイトバランス、黒レベル） |
| サイドカーファイル | 元のファイルの横に置き、付随する情報を記録する別ファイル。本ツールでは、その写真を再現するのに必要な現像パラメータ一式を保存する |
| 書き出し | 現像の結果をファイル（JPEG）に出力すること |
| キャッシュ | 再生成できる中間データ（デコード結果、縮小画像） |
| プロジェクトルート | `pyproject.toml` の `[project] name` が `x3fdev` であるディレクトリ |
| ジオタグ | 撮影位置の緯度経度を画像のメタデータに記録すること |
| GPX ログ | GPS の位置と時刻の記録ファイル（GPX 形式） |

```
tmp/               キャッシュ・ビルド成果物・候補画像（git 管理外。削除可）
docs/              要件・設計
```
